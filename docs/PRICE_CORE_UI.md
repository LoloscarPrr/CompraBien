# Price Core UI

La búsqueda mostrará el mejor precio demo disponible para cada producto.
Al abrir un producto, CompraBien mostrará todas las observaciones disponibles ordenadas por precio.

La interfaz debe indicar explícitamente:

- `DATOS DEMO`
- retailer
- precio actual
- precio de referencia si existe
- descuento calculado si corresponde
- hora de captura
- fuente

Ningún precio demo debe confundirse con información comercial real.
